# 🛒 Customer Shopping Behavior Data Analysis | Python • PostgreSQL • Power BI

This project focuses on analyzing customer shopping behavior to uncover meaningful insights into purchasing patterns, customer preferences, and spending habits.
The analysis follows an end-to-end data analytics workflow, from data cleaning and exploration to SQL-based insights and interactive dashboard visualization.

## 🧰 Tools & Technologies Used
:) 🐍 Python (Jupyter Notebook):<br>
   -> Data import and cleaning<br>
   -> Feature engineering & new column creation<br>
   -> Exploratory Data Analysis (EDA)<br>
   -> Insight-driven analysis using Pandas & NumPy<br>
:) 🛢️ PostgreSQL (SQL):<br>
   -> Structured data storage<br>
   -> Wrote 10+ business-focused SQL queries<br>
   -> Extracted key insights such as customer segments, spending patterns, and product trends<br>
:) 📊 Power BI:<br>
   -> Designed an interactive dashboard<br>
   -> Visualized customer behavior, purchase frequency, and category-wise performance<br>
   -> Focused on clean storytelling for both technical & non-technical users<br>

## Data Source
• Dataset: Kaggle – Customer Shopping Behavior Dataset

## Features / Highlights<br>
-> End-to-end customer shopping behavior analysis using Python, PostgreSQL, and Power BI<br>
-> Raw data cleaning, transformation, and feature engineering for meaningful analysis<br>
-> Exploratory data analysis to understand purchasing patterns and trends<br>
-> Business-focused SQL queries to extract actionable insights<br>
-> Customer segmentation and spending behavior analysis<br>
-> Interactive Power BI dashboard for clear and effective data storytelling<br>
-> Insights designed to support data-driven business decisions<br>
